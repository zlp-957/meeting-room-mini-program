◆项目背景

传统会议室管理（口头沟通、群接龙、纸质登记）存在信息不透明、易重复预订、无法追溯等问题。本项目打造一套企业内部会议室预约系统，采用「微信小程序 + Web 后台」双端架构，实现会议室资源的数字化、流程化、透明化管理。

微信登录流程

Login Flow

采用「微信授权 + 手机号绑定」方案：

wx.login()获取 code
→
code2session换 openid
→
查询用户签发 token
→
getPhoneNumber手机号授权
→
绑定手机号完成注册
关键点：openid 作为用户唯一标识，天然防重复注册；手机号由微信接口安全解密，后端拿到的是微信绑定手机号，用户无需手动输入；token 由 Sa-Token 统一管理。

预约核心流程

Booking Flow
选会议室选时间段
→
提交预约请求
→
冲突检测时间交集
→
创建记录待审批/已通过
→
审批通过签到使用
冲突检测逻辑：同一会议室内，新预约时间区间与已有有效预约存在交集即冲突。
new.start_time < existing.end_time && new.end_time > existing.start_time
